- [raw/articles/2026-09-25-g5-key-precedence-decision.md](raw/articles/2026-09-25-g5-key-precedence-decision.md) — **2026-09-25 — G5 key precedence decided (`4849786`, `8b62e81`): the focused section's programming keys win overlaps.** When both "Program Synth from Keyboard" and "Select Patterns from Keyboard" are on and one key has two jobs, the programming key wins — `C` is synth pitch C rather than 909 pattern 3, `S` is an 808 SD tap rather than 808 pattern 2. Pattern keys keep every job they do not overlap (the digit row still selects Synth 1 patterns while Synth 2 is programmed), which is what ReBirth does, since it offers the two as independent Options-menu checkmarks (manual p. 179, 224) rather than a mode switch. Hardware backs it: the 303's note keys *are* its pattern-select keys, with write/play mode deciding which job they do, and "Program Synth from Keyboard" is the software's write mode. **Rejected:** making the options mutually exclusive — closer to the hardware, but it changes ReBirth's own menu behaviour, which outranks it in the fidelity order. Neither the manual nor any online source settles the overlap. Pinned by the t70 precedence cases. Still **E0** (owner may overrule): Ctrl+Right-Amiga modifier, focus arrows stopping at the ends, both options defaulting off, focus-bar position. *Row added 2026-10-02 — never indexed until now.*
