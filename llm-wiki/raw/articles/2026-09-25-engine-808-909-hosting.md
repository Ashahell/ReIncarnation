## What landed

- `RIEngine` gains `RB808Set` + `RB909Set` (+ per-sound/voice trigger
  stamps), `RI_ENGINE_S808/S909` section bits, `ri_engine_909_bind`
  (non-owning layers; pack loading is a later slice).
- Event consumption: NOTE_ON (lane → sound/voice via m63 tables,
  HIGH flag → accent) → trigger; FLAM → `rb909_arm_flam` (value =
  width); AC to voice ALL → accents voices stamped at this cursor.
- Sections render through the existing insert/pan/send path
  (engine_section), so routing applies to drums unchanged.

## Findings

- The review's "808: no choke at all" is outdated: voice-level choke
  (CH kills OH; 50 ms same-step pre-roll) is implemented and pinned
  (t42). m64 adds no choke code; t57 pins the behavior through the
  engine (same-step OH+CH == CH-solo bit-exactly).
- AC ordering: the AC event sorts after same-sample NOTE_ONs (§8
  priority), so it accents retroactively 303-style. Post-trigger
  accent is exact for both sets (808 excite + 909 gain/shelf read
  v->accent per sample; 909 layers are tune-bound) — no voice changes.
- 909 flam: NOTE_ON (E0 low, no accent) + FLAM event → arm_flam;
  ends the `accent == 2` overload path through the engine.
