## Disposition
New. Closes the rate half of TC-2.13.4 with the key design
finding made during gap analysis: 44.1 kHz export needs NO
resampler — the engine DSP already takes float sr everywhere, so
the offline tool renders natively at the target rate (the header
builder already took sr since the 24-bit slice). What was locked:
the render tool's `RI_SR` plus one fixed 1 s tail constant.
`AudioObject`/live rate stays open (struct has no rate field;
threading it touches Dell-verified 2.7 code — own slice with
on-device proof).
