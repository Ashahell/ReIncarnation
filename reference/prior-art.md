# ReIncarnation — Prior Art Register

**Date:** 2026-09-20
**Purpose:** internet prior art found useful against the spec. Each entry: source, what it teaches, evidence class, spec impact.
**Rule:** entries inform targets and tests; none of them is a parity claim by itself. Ledger entries in `docs/evidence/` remain the normative record.

## 303 DSP lineage

1. **Open303 core constants (Robin Schmidt)** — https://github.com/RobinSchmidt/Open303
   Defaults: normalDecay 1000 ms, accentDecay 200 ms, attacks 3 ms, ampEnv attack 0 / decay 1230 ms / release 0.5 ms normal / 50 ms accent, slideTime 60 ms, accent velocity ≥ 100, envUpFraction 2/3; cutoff/envmod measured mapping (c0 313.8, c1 2394.4, oF 0.0483, oC 0.2944, sLoF 3.774, sHiF 4.195); post-chain HP 44.486 Hz + HP 24.167 Hz + allpass 14.008 Hz + notch 7.5164 Hz BW 4.7; feedback HPF 150 Hz; pitch-slew 0.2×slideTime. Evidence E2. Impact: E2 starting values in §9; post-chain + mapping adopted as defaults.
2. **Open303 stock vs Devil Fish ranges** — header doc comments: filter decay stock 200–2000 ms vs DF 30–3000 ms; accent decay stock fixed 200 ms; amp decay stock ~3–4 s; slide stock 60 ms. Evidence E2. Impact: stock = defaults, DF = extended bounds; accent decay is NOT knob-variable on stock hardware.
3. **Tim Stinchcombe diode-ladder analysis** — https://www.timstinchcombe.co.uk/index.php?pge=diode2
   4-pole diode core with half-value C18 → ~18 dB/oct effective, no self-oscillation; plus 6 poles/6 zeros from coupling caps; sub-resonant ~8 Hz boost measured. Evidence E3. Impact: justifies mismatched-stage tanh cascade + feedback HPF over ideal Moog cascade.
4. **a1k0n x0xb0x resynthesis** — https://github.com/a1k0n/303
   Resonance-loop HPF confirmed; further HP stages strip low end post-filter; cutoff current ∝ filter current (scoped); FFT-fit method documented. Evidence E1. Impact: feedback-HPF + post-HP chain are required blocks.
5. **Sonic Potions µPD650C-133 timing (Julian Schmidt)** — http://sonic-potions.com/Documentation/Analysis_of_the_D650C-133_CPU_timing.pdf
   4/4 gate 3 clocks on / 3 off per 6-pulse step; duty 49.96–55.8% with ms beating; slide latches pitch+accent with ~44 µs pulse even on non-slid notes; gate stays high across slid steps; accent high 2 of 3 on-clocks. Evidence E1. Impact: sequencer timing block in §9 (3-on/3-off, 44 µs latch, tied-gate slide); contradicts fixed-50%-duty models.
6. **Robin Whittle Devil Fish accent analysis** — TB-303 internal-pots/Devilfish notes: accent = (a) MEG decay forced minimum + (b) shortened MEG summed onto VCA (multi-segment, higher peak) + (c) accent-sweep env onto cutoff with buildup on re-trigger. Evidence E3. Impact: dual-envelope accent with buildup state required; single-ADSR-plus-gain models rejected.
7. **Huovilainen (DAFx-04) / D'Angelo–Välimäki (ICASSP-13) nonlinear ladders** — cascade of tanh-embedded first-order sections; Euler vs bilinear ZDF (+12 ops, same nonlinearity count), SPICE-matched distortion; recipe: 2× oversampling, `g=tan(π·fc/fs)`, `u = x − k·y4`. Evidence E0 (Moog topology, transferable). Impact: validates ZDF tanh-cascade candidate family.
8. **Shipped ZDF references (Csound `diode_ladder`, VCV VCF, schwung-303/JC-303)** — zero-delay-feedback diode LPF; 2× trapezoid cascade with input clamp + per-stage saturation, self-oscillation near k=4, output soft-clip; DF decay-split UI (Normal/Accent 30 ms–3 s). Evidence E2. Impact: implementable recipe + decay-split UI mapping precedent.

## 808 / 909 drums

9. **TR-808 Service Notes (1983)** — https://archive.org/details/synthmanual-roland-tr-808-service-notes
   CPU emits COMMON TRIG + per-voice gate; 10 µs step pulse → ~1 ms monostable; accent scales trigger amplitude (4–14 V, 7–14 V for metal voices); bridged-T equations + per-voice freq/decay table. Evidence E0 (manufacturer). Impact: accent as excitation scale, metal-voice range split.
10. **Werner/Abel/Smith 808 kick (DAFx-14)** — decaying sine + ~6 ms >octave attack bump (Q43 shorts R165, ~49–56 Hz → ~130 Hz) + slow leakage sweep; trigger 3.5 V + accent to 10 V; decay 50–800 ms via feedback. Evidence E1. Impact: kick = sine + attack bump + slow sweep, accent-scaled excitation — not a static pitch envelope.
11. **Werner et al. 808 cymbal (ICMC/SMC-14)** — six Schmitt squares (nominal 205.3/369.6/304.4/522.7/800/540 Hz, 5 V, ~48% duty) → dividers → two active BPFs → three swing-VCA bands → Sallen-Key HPFs; needs 4× oversampling at 44.1 kHz. Evidence E1. Impact: metal generator fixed as 6-osc cluster + BPF→VCA→HPF; warp-correction acceptance test.
12. **808 snare dual bridged-T (Werner + Norgatronics)** — revised 173.3 + 336.0 Hz (ratio ~1.93:1); early units 249.6/499.0 vs manual 238/476 typical; VR8 Tone + VR9 Snappy; decay ~25–65 ms. Evidence E3. Impact: two detuned (~1.93×) partials + HP noise; revision-tolerance test (both freq sets pass).
13. **808 clap multi-burst (Baratronix/Thunderclap)** — 30 ms gate → 3×10 ms burst pulses + ~20 ms discharge (~50 ms total) + parallel ~100 ms tail ("reverb" decay); accent into burst-VCA level; bridged-T bandpass. Evidence E3. Impact: clap = 3+1 bursts + separate tail level param, not ADSR noise.
14. **TR-909 hybrid (service manual + ROM extraction)** — analog BD/SD/toms (dual-VCO triangle, ~20 ms pitch-bend, VCA = ENV×ACCENT, 2 ms TRIG + ACCENT latch); digital hats/crash/ride on 32 KB 6-bit companded ROMs (~18–32 kHz playback); hats share one ROM (open/closed can't sound together); crash/ride decay tracks Tune via address-line DAC. Evidence E0 + E2. Impact: Tune = sample clock; accent = VCA scale; shared-ROM voice rule; decay-shortens-with-Tune.
15. **Hydrogen layer model + TR808EmulationKit** — per-instrument components × velocity layers (Hard→Softest) with per-layer gain/pitch in drumkit.xml; 16-FLAC 808 one-shot kit; pattern + MIDI/OSC automation ≈ accent/flam without new engine. Evidence E2. Impact: precedent for layers-per-voice + accent-step gain + flam-as-short-retrigger in the asset schema.
16. **Clean-room pack rules (production guides)** — 100% original renders only; third-party/sample-based libraries typically forbid resale (Splice bars resubmission even modified); deliver 24-bit/44.1 kHz WAV at −0.3 dBFS with per-file proof bundle; own performances of vintage gear low-risk, factory ROM/preset cloning restricted. Evidence E5 (operational). Impact: provenance record + 24-bit QC + licence gate; no ROM dumps or third-party samples in the clean set.

## AROS platform

17. **AmigaOS AHI Device wiki** — https://wiki.amigaos.net/wiki/AHI_Device
   `ahi.device` units via `OpenDevice`, `AHIRequest` (`ahir_Version/Type/Frequency`), double-buffered `CMD_READ/WRITE` streaming + low-level `AHI_SetSound/SetVol`, `AHIAudioCtrl`, `SoundFunc/PlayerFunc` hooks. Evidence E2. Impact: `audio.library` specified as AHI-client with unit-select + format negotiation + double-buffer contract.
18. **AHI v6 source + Aminet release notes** — 8/16-bit mixing (v6 adds 32-bit playback) to 32-bit out, panning, <128 channels, 8-channel multichannel, anti-click zero-crossing search, HiFi linear-interp path, per-card `*.audio` drivers + `AUDIO:` shim (≥20 ms latency limit noted). Evidence E1. Impact: channel/format ceilings + anti-click requirement; latency floor ≥20 ms via shared-device shim.
19. **CAMD + AROS autodocs** — `camd.library` shared realtime MIDI routing; AROS rewrite uses external drivers; `camd` + `realtime` listed first-class in AROS autodocs. Evidence E2. Impact: CAMD + `realtime.library` required; pluggable `DEVS:MIDI/` drivers, no bespoke serial code.
20. **Poseidon USB (`camdusbmidi.class`, transfer map)** — class drivers incl. CAMD-MIDI; MIDI 1.0 → Bulk, MIDI 2.0 → Interrupt; isochronous (USB-Audio) WIP. Evidence E1. Impact: USB-MIDI scoped to Poseidon Bulk; USB-Audio out of scope.
21. **Zune dev docs (BOOPSI/MCC framework)** — Zune on BOOPSI: dispatcher + tag-list methods, `Notify` hierarchy root, MCCs subclass (e.g. Slider) and overload methods, app logic in private Application/Window subclasses. Evidence E2. Impact: knobs/sliders/steps as private MCC subclasses with dispatcher + notify wiring; `Classes/Zune` module gate.
22. **MUI class tree (`Numeric → Knob/Slider/Numericbutton/Levelmeter`)** — canonical header reuse point incl. min/max/step + stringify. Evidence E0. Impact: bind widgets to existing classes; skin only via MCC subclassing.
23. **IFF/ILBM + `iffparse.library` + datatypes** — big-endian `FORM[type] {ID32 size32 data + even pad}`; `PushChunk/PopChunk`, `StopChunk/PropChunk/CollectionChunk`; `8SVX/AIFF/SMUS` audio FORMs; `ILBM→picture.class`, sample→`sound.class`. Evidence E0. Impact: song/skin FORM rules, `PushChunk(IFFSIZE_UNKNOWN)` + pad bytes, datatype-based skin/sample loading.
24. **RB-338 manual + TR-909 manual (behavior)** — 2×303 + 808 (+909 in v2) simultaneously with per-device pattern selectors; Pattern mode loops for editing, Song mode chains patterns + automation with Loop; 808 steps cycle off→weak→strong; 909 global flam-width double-hit on BD/SD/toms, Total Accent (per-step, all voices, knob-scaled) vs per-voice Accent; mods replace samples + GUI, songs bind to a named Mod. Evidence E3. Impact: Pattern/Song split, 2-level accent model, global flam width, realtime-everything, Mod = sample-map + skin bundle. Note: 808 three-state steps vs spec's binary accent — flagged for M2.1 verification.

## Engine methods

25. **Tracktion Engine single-graph renderer** — one node graph for live (`EditPlaybackContext`) and bounce (`Renderer::RenderTask`), live-only inputs excluded at graph-build; documented divergence failure (silent MIDI renders while playback correct). Evidence E1. Impact: supports one-renderer rule; require live-input exclusion test.
26. **Zrythm fixed-PPQ tempo map** — integer ticks at compile-time PPQ, tempo/time-sig events in musical time, cumulative-seconds cache for allocation-free reads, stop-the-world mutation rule. Evidence E1. Impact: supports fixed-PPQ + cached RT reads + stopped-mutation rule.
27. **cochlea-score exact-rational conversion** — per-segment `anchor_sample/anchor_ns`, single widened `mul_div` in u128 with one rounding (Round schedule / Floor lookup), boundary-clamp on reverse lookup; error ±0.5 sample per tempo change, never accumulates. Evidence E0 + E4. Impact: copy-verbatim clock pattern; forbid float playhead; add boundary-clamp tests.
28. **CLAP sample-offset events** — `header.time` offsets in-block, sorted in/out, split-at-boundary scheduling; inline-`process()` (sample-accurate) vs `params.flush()` (offset lost) parameter routes; `CLAP_EVENT_TRANSPORT` for pos/tempo/loop. Evidence E0. Impact: sorted-offset lists, split-at-boundary, flush-vs-process semantics with gesture begin/end.
29. **Bencina RT-101 + lock-free SPSC patterns** — callback must never malloc/free, lock, I/O, block, or run unbounded algorithms; replacement = SPSC FIFOs, by-value messages, buffer-boundary polling, preallocation, completion queues (PortAudio/SuperCollider/JACK rings cited). Evidence E0 + E3. Impact: hard-ban list + command-queue/snapshot architecture + CI grep gate.
30. **cochlea determinism tiers** — T1 byte-identity only on pinned target/toolchain; T2 LUFS ±0.1/onsets ±2 ms/pitch ±5 cents; T3 spectrogram sentinels; bought by pure-Rust `libm` only, no fast-math/FMA (`mul_add` banned), fixed summation order, f64 bus + single f32 rounding, scalar voice ticking. Evidence E2 + E3. Impact: model for D0/D1/D2 claim structure + enforcement list.
31. **alice-det-math deterministic transcendentals** — pure-IEEE-754 kernels (sin/cos/exp/ln/pow/atan2/tanh/…) with max-ulp tables; SIMD lane-identical to scalar; clippy bans + cross-OS SHA-256 golden grid. Evidence E2 + E4. Impact: D2 path enabler — one kernel set, ban platform transcendentals + FMA in DSP.
32. **AudioSnapshotTesting + Pulp Quality Lab** — lossless snapshots + sample-exact compare as truth, failure-only PNGs/spectrograms; SHA/residual gate + six-axis perceptual regression net with level-match; missing/corrupt golden = broken pipeline, never pass. Evidence E2 + E4. Impact: T1 = SHA-256 identity, T2+ = metric tolerances + sentinels, pipeline-broken rule.
