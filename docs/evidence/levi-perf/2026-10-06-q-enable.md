## §Q1: O1 (N=8) + O2 unconditional, with the §0.1 fixes

Fix 0.1.1 (control-rate reset): `filt_clear` now clears `ctl_init`,
`ctl_k`, `morph_hold` and `bank_skipped`. Every note start
(`levi_trigger`) and every `any_on == 0` deactivation runs `filt_clear`,
so the first sample of a note recomputes fresh targets. Legato retune
(`alloc_retune`) deliberately does NOT reset: no envelope restart, pitch
keeps sliding from the old note — carrying the interpolation is correct
there. Voice steal goes through `levi_trigger`, so it resets. Mono and
stereo entries share the reset (both render paths never set control
state except through the unified block).

Fix 0.1.3 (gain interpolation): `evlevel`, `eoplevel`, `edlevel`
interpolate linearly between control points via `ctl_g0/g1` endpoints,
like `dc`/`ac`/`vpitch`. `ereso`, `edrive`, `edenv`, `eaenv`, `edlfo`,
`ealfo`, `evlfo`, `emorph` stay held (comment in code); `emorph` must
stay held so the O2 endpoint test sees exact `0.0f`/`100.0f`.

Fix 0.1.4: `RI_LEVI_CTRL_N 8u` in `levi.h` with a file-scope
negative-array power-of-two typedef (host is `-std=c99`).

Fix 0.1.2 (static-morph gate): skip only when (a) the per-matrix
`mx_has_algo` cache is 0 (refreshed by the same setters as `mx_empty`)
and (b) `emorph` sat exactly at the endpoint for >= 64 samples
(per-voice `morph_hold`, reset in `filt_clear`). Composes with the P2 C6
`liveB_empty` skip (empty bank skips first, no resync). Resync rule
unchanged (live bank states copied into the resumed bank).

P3 prototype bugs also fixed in passing: the mono render's double
`levi_mod_apply` (once outside, once at control points) now applies once
(at control points); the per-sample `voice_pitch_step` is deleted (both
entries use `voice_pitch_eval` + `voice_pitch_advance`, integrals exact).
Two review fixes from the audit run (existing gated tests must stay
green): `voice_pitch_eval` lands instant glide (time 0) at once like the
per-sample path (t135 glide-0 law); the mono render no longer applies the
P9b filter velocity/pressure amounts twice — once at control points into
`tdc`/`tac` and again per sample (t147 mono 40 Hz twins). Neither affects
the §Q1 comparison numbers (dumps and songs render through the stereo
sum; the mono case pins are amount-free).

New gated tests: `t173_levi_ctrlrate` (static determinism + 64/256
invariance; dc targets change only at control points; stale-state law
white-box + 64-sample behavioral; DC-carrier VCA slope law with positive
control) and `t174_levi_bankskip` (skip after hold; LFO->ALGO never;
static NOTE->ALGO never; knob resync + bounds; mono-between-stereo).
Audit gates added next to t172 with one-line FAIL texts.
