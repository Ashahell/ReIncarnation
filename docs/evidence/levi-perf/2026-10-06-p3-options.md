# levi-perf P3: sound-changing options, priced (default off)

All options default OFF. `t172_levi_bitexact` is green with every option
off (each option lives behind a `RI_LEVI_OPT_<NAME>` compile flag; the
shipping build defines none). Nothing below is enabled; the owner picks.

## O1 Control rate (`RI_LEVI_OPT_CTRLRATE`, N = 8/16/32, default 16)

Matrix fold, pitch evaluate and dc/ac targets run every N samples;
dc/ac/vpitch linearly interpolate between points; LFOs, envelopes, banks,
VCA and vintage stay per-sample; pitch time-integrals advance per-sample
(identical trajectory). Static patches are bit-identical (constant targets
interpolate to themselves; demo diff = 0 at all N).

Saving (host bench median of 7, us/voice-sample; exact = current P2 head):

| row | exact | N=8 | N=16 | N=32 |
|---|---|---|---|---|
| matrix empty (16op) | 0.4849 | 0.4805 (-0.9%) | 0.4782 (-1.4%) | 0.4780 (-1.4%) |
| matrix 8 routes | 0.8017 | 0.6724 (-16.1%) | 0.6626 (-17.4%) | 0.6604 (-17.6%) |
| worst | 0.8138 | 0.6773 (-16.8%) | 0.6670 (-18.0%) | 0.6690 (-17.8%) |
| worst-nomx | 0.4765 | 0.4684 (-1.7%) | 0.4671 (-2.0%) | 0.4666 (-2.1%) |
| pan centred | 0.2034 | 0.1994 (-2.0%) | 0.1971 (-3.1%) | 0.1977 (-2.8%) |
| dfilt VOWEL | 0.2593 | 0.2490 (-4.0%) | 0.2478 (-4.4%) | 0.2477 (-4.5%) |

Deviation vs exact (f32 streams):

| content | N=8 max/RMS | N=16 max/RMS | N=32 max/RMS |
|---|---|---|---|
| demo | 0 / -inf | 0 / -inf | 0 / -inf |
| zombie | 0.050 / -71.7 dBFS (-55.7 rel) | 0.061 / -69.8 (-53.8) | 0.061 / -69.1 (-53.1) |
| knife | 0.093 / -80.4 (-62.2) | 0.171 / -69.9 (-51.7) | 0.238 / -65.8 (-47.5) |

Audible risk in one sentence: zipper steps every N samples on
matrix-driven and pitch motion (cutoffs ramp linearly, op levels/pitch
hold), worst on fast LFO->filter at N=32; static patches are untouched.
Recommendation: N=8 (same saving as 16/32 within 1%, -56 dB or better).
Switch: `RI_LEVI_OPT_CTRLRATE` + `RI_LEVI_OPT_CTRLRATE_N` (bench); Dell
run-time knob only if the owner names an N (P4 arm 7).

## O2 Bank skip (`RI_LEVI_OPT_BANKSKIP`)

Skips bank 1's `voice_pass` when `emorph` is exactly 0 (bank 0 when exactly
100). Resync rule: a resumed bank restarts from the live bank's op states
(the `levi_set_morph` join); the join transient is measured, not hidden.

Saving (host bench, median of 7, us/voice-sample):

| row | exact | O2 | saving |
|---|---|---|---|
| morph 0 (4v 16op) | 0.4012 | 0.2791 | -30.4% |
| morph 50 | 0.4073 | 0.4120 | +1.1% (no skip; codegen noise) |
| worst (morph 50) | 0.8129 | 0.8134 | +0.1% |

Deviation vs exact (f32 streams):

| content | max abs | RMS dBFS | note |
|---|---|---|---|
| demo (static morph) | 0 | -inf | identical: skip fires, resync never does |
| zombie-nation | 0 | -inf | identical |
| the-knife | 0 | -inf | identical |
| morph 0->60->0 held + LFO-ALGO oscillation probe | 0.9258 | -11.6 dBFS (-1.2 dB rel) | worst click at an LFO zero crossing |

Audible risk in one sentence: a click, up to full-scale on fast
LFO-driven morph through zero, whenever morph leaves an endpoint during a
held note; silence when morph is static.
Switch: `RI_LEVI_OPT_BANKSKIP` (bench). Dell knob if the owner wants it on
target: none yet (decide first).

## O4 Polyphony cap (`RI_LEVI_OPT_VOICECAP`, N, default 6 when defined)

Refuses new live allocator notes once N voices sound (chord path exempt).
Songs bypass the allocator (direct triggers), so corpus and song output are
bit-identical by construction (t172 perf case FAILs with the flag on at
N=6, proving the switch bites; green with it off).

Saving (P1 voice sweep, host -O2, per 64-sample block): 8v 152.6 us,
6v 114.6 us (-24.9%), 4v 76.7 us (-49.7%). Linear in voices (0.296
us/voice-sample); an 8->4 op "lite" cut would save ~= 4x0.0224 = -0.09
us/voice-sample (~-10% worst) but is NOT built (advisor: last resort).

Deviation: 0 on corpus and all three songs by construction. Live storms
drop notes past the cap (audibility: the owner listens; dropped-note law
is refuse-newest).
Switch: `RI_LEVI_OPT_VOICECAP` + `RI_LEVI_OPT_VOICECAP_N`.

## O3 Float kernels (`RI_LEVI_OPT_FLOATK`)

Single-precision `ri_sin` (order-7, float) and `ri_pow2` (order-6, float)
used for the Levi render TU only (macro-mapped; every other caller,
including the t2/t3 kernel tests, keeps the exact kernels). A first
pow2_f missing its constant term measured 28% relative error and was
fixed before any pricing.

Kernel error (grid): sin maxrel 1.6e-4 (|x|<40), pow2 maxrel 8.4e-6.

Saving (host bench median of 7):

| row | exact | float | saving |
|---|---|---|---|
| matrix empty (16op) | 0.4849 | 0.4016 | -17.2% |
| matrix 8 routes | 0.8017 | 0.6954 | -13.3% |
| worst | 0.8138 | 0.7177 | -11.8% |
| worst-nomx | 0.4765 | 0.3983 | -16.4% |
| pan centred | 0.2034 | 0.1759 | -13.5% |
| dfilt VOWEL | 0.2593 | 0.2275 | -12.3% |
| waves saw x8 | 0.2176 | 0.2161 | -0.7% (no sins; consistent) |

Deviation vs exact:

| content | max abs | RMS dBFS (rel) |
|---|---|---|
| demo | 2.6e-05 | -107.7 (-88.2) |
| zombie | 1.6e-03 | -95.5 (-79.5) |
| knife | 4.4e-03 | -77.2 (-59.0) |

Audible risk in one sentence: a faint detune/noise floor lift on
FM-heavy material (knife worst case -59 dB relative), silent on simple
patches; error grows through FM feedback chains.
Switch: `RI_LEVI_OPT_FLOATK` (bench).

## O5 Denormal handling (FTZ/DAZ via MXCSR)

Counter first: subnormal census over the P0 corpus paths (worst patch +
10 s release tails, quiet sine + 10 s tails), all three full songs
(~500 s), and 2625 block-end scans of every voice state (filter states,
op phase/last/amp, env values, LFO values).

Result: 0 subnormal mix samples and 0 subnormal state hits everywhere.
(`ftz()` already flushes by hand in the hot paths.)

Verdict: no subnormal traffic to reclaim; FTZ/DAZ would change nothing
measurable. NOT priced further, NOT implemented. If a future patch shows
subnormals, revisit with a PMU counter.
Switch: none (probe `RI_LEVI_OPT_SUBNORM_PROBE` kept for re-census).
